# طريقة تشغيل المشروع ورفعه على GitHub

المشروع مرتب بحيث **Jupyter** للتحليل و**Streamlit** لعرض النتائج في موقع تفاعلي.

## 1 — الملفات الموجودة

- `notebooks/Economic_Analysis.ipynb`: دفتر التحليل كامل بعناوين وتفسيرات لكل خطوة.
- `app.py`: الموقع التفاعلي.
- `scripts/build_data.py`: تجهيز وتحويل البيانات وتدريب النماذج وتصدير النتائج.
- `requirements.txt`: المكتبات المطلوبة.
- `data/processed/`: ملفات النتائج التي سيقرأها الموقع بعد تشغيل سكريبت التحضير.

## 2 — البيانات الأصلية

الملف المعدل المرفوع في المحادثة هو Notebook **ولا يحتوي ملف البيانات الخام**. لازم تنسخ ملفك الأصلي:

`API_Download_DS2_EN_csv_v2_146823_LIST.csv`

إلى مجلد `data/raw/` داخل المشروع. **متستخدمش بيانات اختبار أو أرقام مفبركة مكان بياناتك الحقيقية.**

## 3 — التشغيل على جهازك

افتح Terminal في **نفس المجلد الذي فيه `app.py`** وشغّل بالترتيب:

```bash
python -m pip install -r requirements.txt
python scripts/build_data.py
python -m streamlit run app.py
```

هتفتح الموقع في Chrome غالبًا على `http://localhost:8501`.

## 4 — Jupyter

افتح `notebooks/Economic_Analysis.ipynb` لو عايز ترجع للتحليل المفصل أو تغير الأكواد. للتشغيل من البداية لازم الملف الخام يكون في `data/raw/`.

## 5 — رفع GitHub ثم نشر الموقع

1. فك الضغط عن الملف ZIP.
2. حط البيانات الخام الأصلية في `data/raw/`.
3. شغّل `python scripts/build_data.py` وتأكد إن ملفات CSV اتولدت في `data/processed/`.
4. افتح Repo بتاعتك واضغط `Add file > Upload files`، وارفع ملفات ومجلدات المشروع مع الحفاظ على هيكلها (أو استخدم Git لو المتصفح غيّر مسارات المجلدات).
5. **ارفع ملفات `data/processed/*.csv`** علشان موقع Streamlit يشتغل عند أي زائر. متحتاجش ترفع الملف الخام إذا كان نشره غير مسموح؛ Git سيتجاهله بالإعدادات الحالية.
6. افتح `https://share.streamlit.io/`، واختار Repo والفرع `main` وحدد ملف `app.py` واضغط Deploy.

الرابط العام ما بيتعملش تلقائي من ملف Jupyter، ولا من `localhost`؛ لازم خطوة Streamlit Cloud بعد GitHub.
